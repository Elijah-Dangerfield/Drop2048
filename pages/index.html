Doublestack

Blocks fall. Matching numbers double.

A block drops into a narrow grid. You steer it, and if it lands on a block with the same number the two merge and double. Chains happen when one merge sets up the next. There are wildcards that double whatever they land on, bombs that clear a few cells, and stones that do nothing at all. It gets faster as you go, and if you get a block to 2048 the row blows up.

It runs offline. There is no account, no email and no password.
